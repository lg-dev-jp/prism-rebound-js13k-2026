# PRISM REBOUND

[English README](README.md)

「気持ちのいい一発のショット」「7色のターゲット」「そこから広がる連鎖反応」を中心にした、コンパクトな疑似3D物理スコアアタックゲームです。

光るボールを引っ張り、角度とパワーを決めて離します。壁へのバンクを使いながら色付きターゲットを壊し、衝突を長く気持ちのいい連鎖につなげていきます。

## プレイ

https://lg-dev-jp.github.io/prism-rebound-js13k-2026/

## 操作

- **ドラッグ / 引っ張る**：方向とパワーを決める
- **離す**：ショット
- **RETRY**：現在のステージをやり直す。現在のステージスコアはRUN TOTALへ加算しない
- **NEXT**：現在のステージスコアをRUN TOTALへ加算して次へ進む
- **NEW RUN**：Stage 3終了後、現在のランを終了してStage 1へ戻る
- **R**：現在のステージをリスタート
- **Audio**：サウンドON / OFF

## スコア

破壊、バンク、連鎖によって **STAGE SCORE** を伸ばします。

7色すべてを破壊すると **Spectrum bonus** を獲得。3つのステージを通してスコアを持ち越し、最高の **RUN TOTAL** を目指します。

各ステージのベストスコアを保存し、Stage 3終了時には3ステージを通したRUN BESTも記録します。

## ステージ

1. **ORBIT** — バンクを狙う円形寄りの配置
2. **CROSSCUT** — 交差する連鎖を狙う配置
3. **GLASSHOUSE** — 密集した配置をまとめて破壊

## サウンドと13KB

PRISM REBOUNDは、ショットしている瞬間だけでなく、ゲームを起動している時間そのものも心地よく感じられるように作っています。

音楽と効果音はWeb Audioによってブラウザ上でリアルタイム生成されています。柔らかくループする音楽、ポンポンと弾けるような軽快な衝突音、アクションに反応する音階付きの効果音を使用しています。

外部画像、外部音声ファイル、外部ライブラリは使用していません。グラフィック、疑似3D表現、物理演算、サウンドのすべてが13KBのゲーム内に収まっています。

js13kGames提出用ZIPは `index.html` のみで構成し、**13,312 bytes以下**に収めています。
