# PRISM REBOUND

[English README](README.md)

**js13kGames 2026** 向けに制作している、疑似3D物理スコアアタックゲームです。

ボールを引っ張って角度とパワーを決め、ステージへ発射します。  
壁へのバンク、ボール同士の弾性衝突、連鎖破壊を利用してスコアを伸ばし、7色すべての破壊を狙います。

## 操作

- **ドラッグ / 引っ張る**：方向とパワーを決める
- **離す**：ショット
- **RETRY**：現在のステージをやり直す。現在ステージのスコアはRUN TOTALへ加算しない
- **NEXT**：現在ステージのスコアをRUN TOTALへ加算し、次のステージへ進む
- **NEW RUN**：3ステージ終了後、新しいランをStage 1から開始
- **R**：現在のステージをリスタート
- **Audioボタン**：サウンドON/OFF

## スコア

- **STAGE SCORE**：現在プレイ中のステージで獲得したスコア
- **RUN TOTAL**：3ステージを通した現在の合計スコア
- バンクや長いCHAINを狙うほどスコアを伸ばせる
- 7色すべてを破壊するとSpectrumボーナス
- 各ステージのベストスコアを保存
- Stage 3終了時に3ステージ合計のRUN BESTを保存

## ステージ

1. **ORBIT** — バンクを狙う円形寄りの配置
2. **CROSSCUT** — 交差する連鎖を狙う配置
3. **GLASSHOUSE** — 密集した配置をまとめて破壊

## js13kGames提出版

大会提出用ZIPには `index.html` だけを入れます。

提出ZIPは **13,312 bytes以下**にします。

外部画像・音声ファイル・ライブラリ・ネットワーク取得は不要です。  
グラフィック、疑似3D投影、物理挙動、サウンドはブラウザ上で生成します。

## 開発

AIを利用したプロトタイピングと反復開発を含みます。ゲームの方向性、プレイテスト、最終判断は制作者が行っています。
